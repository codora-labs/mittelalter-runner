# Mittelalter Runner

A medieval jump & run platformer built with [Flutter](https://flutter.dev).

**[Play now](https://codora-labs.github.io/mittelalter-runner/)**

## How to play

- **A/D** or **arrow keys** — move left/right
- **W** — jump
- **F** or **Enter** — shoot arrows

Collect arrows from Lucky Blocks, defeat enemies, and advance through procedurally generated levels.
